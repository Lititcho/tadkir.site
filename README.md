# تذكير | TADKIR
## التشغيل محليًا
`cd tadkir && python3 -m http.server 8080` ثم افتح http://localhost:8080 (لا تستخدم file://).
## اختبار التثبيت والعمل دون إنترنت
1. افتح الموقع مرة واحدة متصلًا، ثم من الإعدادات اضغط «تحميل القرآن كاملًا».
2. في Chrome: DevTools ← Application ← Service Workers ← Offline، ثم أعد التحميل.
3. التثبيت: القائمة ← «تثبيت التطبيق».
## النشر
ارفع المجلد كما هو على استضافة HTTPS (GitHub Pages / Netlify / Cloudflare Pages).
## القيود
- القرآن: يُجلب من alquran.cloud ويُخزَّن في IndexedDB بعد التحقق من عدد الآيات. يحتاج القراءة دون إنترنت تحميلًا مسبقًا.
- الخطوط: خطوط النظام (لا اعتماد على خطوط خارجية حتى يعمل كل شيء دون إنترنت).
- «تواصل» يفتح تطبيق البريد (mailto) ولا يوجد خادم.
- لا يوجد ودجت أندرويد أصلي.
